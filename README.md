# Конвертер JSON в 1С 7.7

Этот проект предоставляет инструменты для конвертации данных JSON в формат, совместимый с 1С 7.7.

## Файлы:

*   `conversion_rules.txt`: Определяет правила конвертации JSON во внутренний формат 1С 7.7.
*   `json_to_1c.py`: Скрипт Python для выполнения конвертации.
*   `json_to_1c_77.js`: Скрипт JavaScript, вероятно, связанный с процессом конвертации для 1С 7.7.
*   `test.json`: Пример входного файла JSON.
*   `test.ert`: Пример выходного файла или тестовый файл для 1С 7.7.

## Использование:

### json_to_1c.py

Этот скрипт конвертирует файл JSON в формат 1С 7.7 "СписокЗначений".

**Предварительные требования:** Python 3

**Как запустить:**

```bash
python json_to_1c.py <input_file.json> [-o <output_file.txt>]
```

*   `<input_file.json>`: Путь к входному файлу JSON.
*   `-o <output_file.txt>` или `--output_file <output_file.txt>`: (Необязательно) Указывает путь для выходного файла. Если не указан, сконвертированное содержимое будет выведено в консоль (стандартный вывод).

**Пример:**

Для конвертации `test.json` и вывода результата в консоль:

```bash
python json_to_1c.py test.json
```

Для конвертации `test.json` и сохранения результата в `output.txt`:

```bash
python json_to_1c.py test.json -o output.txt
```
