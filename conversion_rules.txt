# Правила преобразования типов данных 1С 7.7 в текстовый формат при выгрузке через ЗначениеВФайл()

## 1. Общая структура

Объект `СписокЗначений` сериализуется в текстовое представление, заключенное в фигурные скобки `{}`.

- **Формат:** `{"VL", {{элемент1}, {элемент2}, ...}}`
- `VL` обозначает `СписокЗначений` (ValueList).
- Каждый `элемент` представляет собой пару `{сериализованное_значение, "ключ"}`.

## 2. Формат сериализованного значения

Каждое простое значение (число, строка, дата) сериализуется в формате:
`{"<код_типа>", "0", "0", "0", "0", "0", "<текстовое_представление_значения>"}`

## 3. Правила для конкретных типов

### Число (Number)
- **Код типа:** `N`
- **Значение:** Преобразуется в строку. В качестве десятичного разделителя используется точка (`.`).
- **Пример из кода:** `123.45` -> `{"N",...,"123.45"}`

### Строка (String)
- **Код типа:** `S`
- **Значение:** Используется как есть. Если внутри строки встречаются кавычки (`"`), они удваиваются (`""`).
- **Пример из кода:** `"Пример ""строки"""` -> `{"S",...,"Пример ""строки"""}`

### Дата (Date)
- **Код типа:** `D`
- **Значение:** Преобразуется в строку формата `ГГГГММДД` (YYYYMMDD) без разделителей.
- **Пример из кода:** `Дата("01.11.2024")` -> `{"D",...,"20241101"}`

### СписокЗначений (ValueList), вложенный
- **Код типа:** `VL`
- **Значение:** Для вложенного списка рекурсивно применяется то же правило сериализации, что и для основного.
- **Пример из кода:** `МассивЗначений` -> `{"VL",{{{"S",...,"Один"},"1"}, ...}}}`
